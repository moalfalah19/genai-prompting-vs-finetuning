# GenAI Prompting vs Fine-Tuning

This project compares prompting and fine-tuning techniques for multimodal fact-checking using Large Language Models (LLMs).

The system classifies claims based on supporting evidence and predicts whether the claim is supported, refuted, or unverifiable.

## Features
- Prompt engineering with in-context learning
- Fine-tuning using quantized LLMs
- Evaluation using Accuracy, Precision, Recall, and F1-score
- Multimodal fact-checking pipeline

## Technologies
- Python
- PyTorch
- Ollama
- Unsloth
- LLMs

## Goal
The goal of the project is to analyze the trade-offs between prompting and fine-tuning for fact-checking tasks.
